mend is one command-line patch tool for every AI edit format: unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON edits. It finds the lines each edit names at the first of three matching tiers (exact, trailing-whitespace-tolerant, leading-and-trailing-whitespace-tolerant with re-indentation) and writes every change or none. Node 22, standard library only. Practice score 100/100.

## Run it

```sh
node main.ts [options] [PATCH]
```
